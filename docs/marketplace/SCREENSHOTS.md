# Screenshots checklist

Marketplace allows up to 5 screenshots plus a highlight image for each of the 3 highlights.
Capture them at **1840×900**, which Marketplace scales to 920×450. Use the light theme, the
fresh-site demo project FMD, and no personal names apart from the seeded demo users.

| # | Screen | How to get there | Must show |
|---|---|---|---|
| 1 | Command Center overview | Jira → FMD → Apps → Foreman | Risk score, heatmap (Level 2 / MEP hot), open problems list |
| 2 | Timeline | Overview → Permit and inspection timeline | Critical path, I5 before I4 flagged, P1 expiry marker |
| 3 | Code review | Issue panel on the A-201 Code Finding → Code review | Findings with IBC citation and verbatim quote (55 ft dead-end corridor) |
| 4 | Evidence split view | Issue I2 → Field evidence & report → Generate verified report | Report lines ↔ photo highlight, S-101 contradiction flagged |
| 5 | Approval queue | Command Center → Approval queue | Proposals with source ("Proposed by the Foreman monitor" / "in Rovo chat") |
| H1 | Rovo chat | Rovo → Foreman agent: "What are the top risks on FMD?" | Agent answer with real problem names and links |
| H2 | Confluence report | The published report page | Signed-off report with evidence references |
| H3 | Teamwork Graph context | Issue → Context tab | People involved, decisions, related specs |

## Before capturing

- [ ] Run the monitor once so the risk score and the digest have data.
- [ ] Add the demo decisions and spec pages so the Context tab is full.
- [ ] Close any Jira banners and the onboarding checklist.
- [ ] Set browser zoom to 100%.
- [ ] Hide or blur the site URL if it shows a personal name.
